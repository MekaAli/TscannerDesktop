# 📄 Tscanner Desktop

**Tscanner Desktop** is a lightweight, fast, and intuitive desktop utility for high-accuracy document scanning, OCR (Optical Character Recognition), and tabular data extraction. Powered by an advanced AI engine, Tscanner converts printed/handwritten documents and images directly into clean, editable text and tabular CSV formats.

---

## ✨ Features

- **⚡ Instant OCR Processing:** Extract text from printed and handwritten documents accurately in seconds.
- **📊 Table & Data Extraction:** Automatically parse formatted data, invoices, and receipts into clean `.csv` files.
- **📄 Document Formatting:** Seamlessly export extracted content into editable `.docx` (Word) or plain text formats.
- **🎨 Modern Desktop Interface:** Built with a clean PyQt interface for effortless drag-and-drop workflows.
- **🚀 Ultra-Fast Pipeline:** Connects to a high-speed cloud OCR engine for real-time extraction without heavy local CPU usage.

---

## 📥 Download & Installation

### Windows (Quick Start)

1. Go to the **[Releases](../../releases)** page.
2. Download the latest `TscannerDesktop-v1.0.0-win64.zip` asset.
3. Extract the `.zip` archive to your preferred location.
4. Run `TscannerDesktop.exe` to launch the application.

> **Note on Windows SmartScreen:**  
> Because the application is not signed with an enterprise EV Code Signing Certificate, Windows Defender or SmartScreen may show a *"Windows protected your PC"* warning on first launch. Click **More info** $\rightarrow$ **Run anyway** to launch the application safely.

## 💻 Tech Stack

- **UI Framework:** Python & PyQt

## 🔒 Privacy & Security

Tscanner processes document images securely for text conversion. Images sent for processing are analyzed in memory and are not stored permanently or shared with third parties.
